## Overview
SQL Cockpit Server 0.0.1 is a **Hello World installer and release integration test**, not production-ready.

## Added
- Minimal Electron/React/TypeScript placeholder displaying Hello World and the installed version.
- Different payload directories for Windows, macOS and Linux, selected during packaging.
- Platform payload validation at startup.
- GitHub release installers and SHA256 checksums.

## Windows
- x64 EXE installer. Unsigned test build; no signing certificate configured.

## macOS
- Separate Apple Silicon (arm64) and Intel (x64) DMGs.
- Ad-hoc signing only; no Developer ID certificate or notarization.

## Linux
- x64 AppImage. Make executable before launching; FUSE may be required.
- Unsigned test build.

## Known limitations
- **Does not run a server, connect to databases or install a background service.**
- No automatic updates. This tests installation, platform payloads and release feeds only.
- Windows and Linux ARM builds are not included.
